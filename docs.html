شكل الأخطاء

كل الأخطاء بنفس الشكل، ورمز code ثابت يمكن التعامل معه برمجيًا.

{ "error": { "code": "forbidden", "message": "Admin only", "request_id": "…" } }

الدخول الموحد لتطبيق جديد

1) أنشئ code_verifier عشوائيًا (43–128 حرفًا) و code_challenge = base64url(SHA-256(verifier))
2) حوّل المستخدم إلى صفحة الدخول المركزية مع client_id و redirect_uri و code_challenge و state
3) بعد العودة: تحقق من state ثم
   POST /sso/token { grant_type:"authorization_code", client_id, code, code_verifier, redirect_uri }
4) استخدم access_token (صالح ١٥ دقيقة) في Authorization header
